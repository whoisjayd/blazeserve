# BlazeServe documentation

These guides explain how to use BlazeServe, from sharing a single file to running it in production. Start with the first one and read on as far as you need.

| Guide | Read it when you want to |
| :--- | :--- |
| [Getting started](getting-started.md) | Install BlazeServe and serve your first folder |
| [Sharing and downloading files](sharing-files.md) | Send a file to someone, or download and upload with resume |
| [Serving files](serving-files.md) | Run a proper file server: passwords, HTTPS, hidden files, speed limits |
| [Uploads](uploads.md) | Let people send files to your server safely |
| [Monitoring](monitoring.md) | Watch health, metrics, logs and traces |
| [Security](security.md) | Understand what BlazeServe protects you from, and what it does not |
| [Python and Rust](python-and-rust.md) | Start a server from your own code |
| [Performance](performance.md) | Measure speed on your own machine |
| [Telemetry](telemetry.md) | See exactly what anonymous usage data is sent, and how to turn it off |
| [Troubleshooting](troubleshooting.md) | Fix the most common problems |
| [Upgrading from 0.x](upgrading.md) | Move from the old Python version |
| [Reference](reference.md) | Look up every option, endpoint, setting and exit code |

Deployment files for Docker, Kubernetes, systemd and reverse proxies are described in [deploy/README.md](../deploy/README.md). If you want to change BlazeServe itself, read [CONTRIBUTING.md](../CONTRIBUTING.md).
